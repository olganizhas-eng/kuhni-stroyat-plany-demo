# Текстуры материалов

Все карты — с ambientCG (https://ambientcg.com), лицензия Creative Commons CC0 1.0 Universal
(https://docs.ambientcg.com/license/): можно использовать, менять и распространять, в том числе коммерчески, без указания автора.
Скачаны 13.10.2026 в разрешении 1K, сжаты: цвет 1024 px, рельеф (normal, OpenGL) и шероховатость 512 px.

| Папка | Материал ambientCG | Где в конфигураторе |
|---|---|---|
| oak | Wood095 | шпон дуба, цоколь под дерево, массив дуба, стены «Брус» |
| walnut | Wood051 | шпон ореха |
| calacatta | Marble014 | столешница «Calacatta» (керамогранит под мрамор) |
| black-stone | Marble016 | чёрная столешница (компакт-ламинат под камень), матовая |
| white-quartz | Granite002A | белый кварц (цвет осветлён, контраст снижен) |
| plaster-wall | PaintedPlaster017 | стены «Обои» |
| parquet | WoodFloor051 | паркет «Обои» |
| concrete-wall | Concrete036 | стены «Лофт» |
| concrete-floor | Concrete048 | керамогранит «Лофт» |
| laminate | WoodFloor062 | ламинат «Брус» |

Это текстуры реальных материалов, но не декоры конкретных производителей (Egger, Caesarstone и т. п.).
